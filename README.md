# RaiseAMob resource pack

The resource pack for the RaiseAMob Minecraft server (play.raiseamob.net): gem and coin icons, the logo and the Gem Store gem. The server sends it to players automatically; it is built from the server's source and published here because Minehut and MineKeep only allow packs hosted on GitHub.

`dui.zip` is the pack for the in-game Gem Store window, generated by [dui](https://github.com/Kembel-Entertainment/dui)
(MIT, commit dd5ba06) from the official Minecraft 26.3 client. It replaces the game's text shaders, so the server sends
it only to players on 26.3. It contains material derived from Minecraft (shifted fonts, item wrappers), which is not
covered by dui's licence.
